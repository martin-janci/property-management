## Open security risks (top 3)

### RISK-1 — `security-test-gate.yml` enforcement unconfirmed (HIGH impact)

`security-test-gate.yml` is present in `.github/workflows/` but remains unconfirmed as a **required** status check on `dev`. PR #497 (a security IDOR fix) merged with zero tests despite the gate; the #1507 IDOR-test restoration confirms the test infrastructure can be gated but the CI guard is advisory-only. Until this is a blocking required check, every security-tagged PR can merge with no regression test.

- **Evidence:** Issue #1538 — backend `test` job not required; `dev` branch protection requires only `check`.
- **Probability:** medium | **Impact:** high
- **Mitigation:** `gh api repos/.../branches/dev/protection` to confirm; add `security-test-gate` + `test` job as required checks.

### RISK-2 — `PortalPrincipal` owner-scope bypass open (MEDIUM/HIGH impact)

Follow-up #1584 (OPEN) documents that `PortalPrincipal` bypasses `reality_agency_members` and rides on an `agency_id = user_id` mismatch in 3 specific flows. PR #1603 pinned finding-3 but findings 1-2 remain unaddressed. An authenticated portal user can potentially act on another agency's import jobs or feed subscriptions if they know the IDs.

- **Evidence:** #1584 open, findings 1-2 not yet closed.
- **Probability:** medium | **Impact:** high
- **Mitigation:** Address #1584 findings 1-2: add `reality_agency_members` membership check to the flagged `PortalPrincipal` paths; add regression tests before next reality-server deploy.

### RISK-3 — `pm-security-audit-hash-debug-format-p1-04` still open (MEDIUM/MEDIUM impact)

P1-04 residual from the original deferred PR #435 findings: internal type internals may reach audit-trail log lines via `Debug ({:?})` formatting. Carrying since 2026-05-25 with no assigned implementer. Combined with the accounting UI auth-interceptor bypass (#1522, OPEN) — which means accounting calls can reach the API without the standard auth headers — there are two non-trivial data-leak surfaces without assigned owners.

- **Evidence:** `risks.json` item `pm-security-audit-hash-debug-format-p1-04`; issue #1522 (OPEN, no auth interceptor on accounting UI).
- **Probability:** medium | **Impact:** medium
- **Mitigation:** Assign pm-security to both: replace `{:?}` with structured Display fields; fix accounting UI to route through `@hey-api` auth interceptor (issue #1522).
